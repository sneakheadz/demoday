## Getting Started / Running Demos

To explore or run the demos:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/sneakheadz/demoday.git](https://www.google.com/search?q=https://github.com/sneakheadz/demoday.git)
    cd demoday
    ```
2.  **Navigate to a specific project directory:**
    ```bash
    cd [project-name-1]/
    ```
3.  **Follow the instructions:** Look for a `README.md` file within that directory for specific prerequisites (e.g., Node.js version, Python environment, Docker, API keys) and setup/run commands.
